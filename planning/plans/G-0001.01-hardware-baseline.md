# G-0001.01. Hardware baseline

Status: In progress
Goal: [G-0001](G-0001-trustworthy-live-investigation.md) — each built-in capability initializes reliably with known ownership.
ADRs: [0003](../adrs/ADR-0003-tab5-diagnostic-foundation.md), [0004](../adrs/ADR-0004-capture-completion.md), [0005](../adrs/ADR-0005-diagnostic-radio-startup.md)

## Hypothesis

A pinned native toolchain with one owner per peripheral can repeatedly initialize this Tab5's built-in capabilities, and the observed inputs/outputs are attributable to specific hardware.

**Refuted if:** a required peripheral fails repeatably, two stacks compete for one resource, detected hardware lacks a supported driver, or a clean rebuild does not reproduce startup.

## Checks

1. [pass] Inventory: record actual chip, panel, camera, flash/PSRAM and C6 firmware identity.
2. [open] Reproduction: two clean builds from pinned inputs boot; **10 cold starts and 10 software resets** with zero init failures.
3. [pass] Function: camera frame retained; mic capture + playback heard; touch reaches corners/center; IMU follows tilt; RTC advances; SD checksum round trip; Wi-Fi LAN round trip; physical mic mapping recorded.
4. [open] Ownership: each resource has one named owner; nothing is initialized twice.

Out of scope: concurrency (.02), calibration (.03), agent (.04), power/wake (.05). USB/RS-485 need fixtures and are deferred.

## Observed

- 2026-09-20 — Identity: P4 v1.3, 16 MB flash, 32 MB PSRAM, ST7121 panel, C6 fw 1.4.1, BMI270 `0x24`, INA226 `0x5449`, camera PID `0xeb52` (SC202CS driver; marketing name differs). Original flash backed up twice, hashes match. Evidence: `20260920-baseline/recovery.json`.
- 2026-09-20 — Two clean factory builds boot; differences are timestamps only. BSP default display buffers abort in PPA; factory full-frame PSRAM buffers work. → ADR-0003.
- 2026-09-20 — Touch (4 corners + center) and tilt response recorded (`diagnostic-input-1`). RTC advances.
- 2026-09-20 — Camera 1280×720 RGB565 frame and 3 s four-slot 48 kHz PCM exported with matching hashes after fixing a vendor G_FMT bug (`media-boot-2`). → ADR-0004.
- 2026-09-20 — Hosted radio startup aborted (TCM task stack, then early heap exhaustion). Fixed by deferring radio init and constraining task RAM (`acoustic-network-3`). → ADR-0005.
- 2026-09-20 — LAN: three nonce echoes 263/35/39 ms (`lan-echo-1`). First joins failed until the correct network was chosen.
- 2026-09-20 — Playback: phrase audible in raw slots 0/2 on speaker (faint) and both headphone ears; slots 1/3 static.
- 2026-09-20 — Software resets: first run panicked from an LVGL startup race; fixed by holding the display lock. Ten `ESP_RST_SW` boots then passed (`software-restarts-2`).
- 2026-09-20 — Mic mapping: slot 2 ↔ hole near USB connector, slot 0 ↔ farther hole (±0.7–2.8 dB margins, three takes each) (`audio-ingress-1/microphone-position.json`).
- 2026-09-20 — Vendor IMU helpers ignored Bosch errors; replaced with checked init/read (`imu_checked`).
- 2026-09-22 — SD card installed: write/readback checksum and LAN download pass; about 3.0 s per 1.15 MB capture (`20260922-sd-testing`).
